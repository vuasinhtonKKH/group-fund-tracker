# Project Title
Group Fund Tracker Smart Contract

# Project Description
Managing collective funds in a group often lacks transparency and requires trusting a single person to hold the money. This project utilizes the Soroban smart contract platform on the Stellar network to ensure all group contributions are recorded transparently and immutably.

# Project Vision
To create a decentralized, trustless environment for small groups, clubs, and communities to manage their shared finances without relying on a centralized custodian.

# Key Features
* **Secure Deposits:** Users can securely contribute tokens to the group fund.
* **Track Individual Balances:** Anyone can verify how much a specific user has contributed.
* **Track Total Fund:** Provides a real-time summary of the total assets held by the group.
